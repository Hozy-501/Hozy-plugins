# Hozy Token Command

A Valenced plugin for Discord (Android) that lets you safely extract and view your Discord account token using a local `/token` command. The result appears only to you as a local ephemeral embed — no one else in the chat sees it.

---

## Features

**Local `/token` command** — type `/token` in chat (it appears in the slash menu) to retrieve your account token

**Ephemeral output** — your token displays inside a clean local embed visible only to you

**Privacy-focused** — execution happens locally on your device and never sends your token to any server

**Easy copying** — long-press the embed text to copy your token directly to your clipboard

**Clean teardown** — all patches are removed when the plugin is disabled, leaving no memory leaks behind

---

## Installation

1. Open Discord and go to **Settings → Valenced → Plugins**
2. Tap the gear icon in the top-right corner
3. Paste the repository URL and tap **Add repository**
4. Go back to the Plugins page and tap **[+]**
5. Find **Hozy Token Command** and install it

---

## How to use

1. Open any server channel or DM
2. Type `/token` and tap send
3. The token embed appears right in the chat — only you can see it

---

## Command Details

| Command | Action | Visibility |
|---|---|---|
| `/token` | Displays your current account token in an embed | Local only (Ephemeral) |
